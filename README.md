# 📱 React Native Chat App

A cross-platform chat application built with **React Native**, **Expo**, and **React Navigation**. This project showcases a simple, clean chat UI with user authentication and message handling features.


---

## 🚀 Features

- 📱 Cross-platform: Android & iOS support  
- 💬 Real-time chat interface using `react-native-gifted-chat`
- 🔐 User authentication (with Firebase integration)
- 📲 Navigation using `React Navigation`
- 🎨 Clean and modern UI with reusable components
- 🌙 Light theme by default

---

## 📦 Tech Stack

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [React Navigation](https://reactnavigation.org/)
- [Firebase (optional for authentication)](https://firebase.google.com/)
- [react-native-gifted-chat](https://github.com/FaridSafi/react-native-gifted-chat)
